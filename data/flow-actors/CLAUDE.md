# data/flow-actors/ — 수급 주체·세력 (Flow & Actors)

> 목적: **누가 사 모으는가** — 기관·외국인·개인·특정 창구(증권사 지점)의 매매 패턴.
> "꾸준한 매집 시그널"의 직접 증거가 모이는 곳.

## 다루는 데이터
- 투자자별 순매수(기관/외인/개인), 프로그램 매매
- 창구(거래원)별 매수·매도 상위, 공매도/대차잔고
- (crypto) 지갑/고래 흐름, 거래소 입출금(공개 온체인만)

## 관찰 후보 시그널 (가설 — 단정 금지)
- 특정 창구의 **지속·일관된 순매수**(분산 매집 의심)
- 외인/기관 표면 무관심 속 특정 창구 누적
- (crypto) 소수 지갑 집중 + 거래소 유입 패턴

## 윤리
- 공개 집계 데이터만. 특정 개인 계좌 추적·지목 금지. 창구는 기관 단위로만.

## 스키마(추가 필드)
```
actor_type(inst/foreign/retail/broker/whale), net_buy, broker_code,
short_balance, onchain_flow
```
