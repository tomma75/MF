# data/sentiment/ — 커뮤니티·여론 심리 (Crowd Sentiment)

> 목적: 종목토론방·SNS·텔레그램 등의 **군중심리 언어 데이터** 수집.
> 이 프로젝트의 "사람들의 심리 분석" 축이 여기서 출발한다.

## 다루는 데이터
- 종토방/카페/SNS/텔레 메시지량·게시글수, 키워드 빈도
- 감성(공포/탐욕/확신), 군중 언어 패턴("가즈아", 평단 인증, FOMO 표현)
- 리딩방·단톡방 신호(출처·익명화 필수)

## 윤리 (필수)
- **개인 식별정보 제거/익명화.** 실명·연락처·계좌 캡처 금지.
- 실존 인물 단정·비방 금지(루트 윤리 규칙 상속).

## 관찰 후보 시그널 (가설 — 단정 금지)
- 급등 *전* 게시글/멘션 **이상 급증**(동원 의심) vs 급등 *후* 급증(추격)
- 확신·재촉 언어 비중 상승, 반론 게시글 억압/도배
- "조용한 매집기"엔 오히려 관심 저조 → 침묵의 대비

## 스키마(추가 필드)
```
platform, post_count, mention_count, sentiment_score, keyword_freq{},
sample_texts[](익명화)
```
+ 공통 필드. 심리 지표는 **상대값/표준화**로(절대 게시글수는 종목 크기에 종속).
