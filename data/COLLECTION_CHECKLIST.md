# 데이터 수집 체크리스트 (Collection Checklist)

> 수집 모드: 혼합(수동+자동) → 검증 후 자동화. 모든 레코드가 아래를 만족해야 유효.

## 레코드 진입 조건 (필수)
- [ ] `asset_class` 태그 존재
- [ ] `observed_at` **와** `published_at` 둘 다 기록 (as-of 동결)
- [ ] `source` + `url` 존재 (근거 없으면 폐기)
- [ ] 심볼 미검증 시 `id_unverified=true`
- [ ] 원형(raw) 보존 — 가공본은 별도, raw 덮어쓰기 금지

## as-of 동결 (look-ahead 방지) — 특히 disclosure-news
- [ ] `published_at` = 원천 실제 공개시각 (내가 발견한 시각 아님)
- [ ] 사건(t0) **이후** 소급 해석된 정보로 과거 레코드 오염 금지
- [ ] 정정공시/재크롤은 **최초 published_at 고정**, 이중계상 금지
- [ ] sentiment: 사후 삭제분 생존편향 주의 — 실시간 스냅샷 불가 항목은 신호 무효

## 윤리 (위반 금지)
- [ ] 공개 데이터만 (비공개·내부정보·약관위반 스크래핑 금지)
- [ ] 개인식별정보 제거/익명화 (sentiment 샘플, flow 개인계좌/지갑)
- [ ] 실존 인물·세력 단정·비방 금지 → 기관/클러스터 단위 일반화

## 사건축 정렬 (labeling 연계)
- [ ] t_start/t0는 **규칙기반 사전확정** (PCR-MS), 당국이벤트(detection_time)를 t0로 쓰지 않음
- [ ] 선행 시그널 피처는 **t0 이전 창**에서만 추출 (누출 회귀테스트 통과)

## 자산군별 주의
- **kr_stock**: 상·하한(±30%), 동시호가, VI, 유통주식수 as-of 동결
- **crypto**: 24h 무정지·상한 없음 → 정규화 다름, 온체인은 블록높이 동결
- **global_stock**: 거래소·시간대 분리, OTC/핑크시트 배제
