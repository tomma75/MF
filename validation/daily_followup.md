# 매일 F/U 학습 로그 (Daily Follow-Up & Learning)

> 목적: `collapse_predictions.md`의 붕괴 타이밍 예측을 **매 거래일 실제와 대조**하고,
> **맞으면 어떤 근거로 맞았는지 / 틀리면 왜 틀렸는지**를 기록해 예측 모델을 학습시킨다.
> ⚠️ 가설적 시나리오의 사후 검증이며 **매매 신호가 아니다.** 사후합리화 금지 — 반증조건 충족 시 즉시 '오류'로 기록.

## 기록 규칙
1. 각 거래일 1개 블록 추가(과거 블록 수정 금지 = as-of 동결).
2. 상태 변화가 있는 종목만 표기(무변화는 "변동 없음"으로 요약).
3. 예측창 도래/경과 시 **판정**: `HIT`(예측창 내 붕괴/트리거 발생) / `MISS`(창 경과·미발생 또는 반대) / `PENDING`(창 이전) / `EARLY`(창 이전 붕괴) / `VOID`(반증조건 충족→예측 무효).
4. HIT/MISS마다 **학습 노트**: 무슨 신호가 선행했나 / 어떤 가정이 틀렸나 / 트리거 모델 수정점.
5. 데이터 출처 병기(가격·공시·시장경보). KRX/DART 원문 접근 불가 시 언론 교차로 표기하고 신뢰도 명시.

- 락업 있는 사모 CB는 발화 직후 창에서 전환 트리거가 '구조상 발화 불가'(넥써쓰 2027.6, 중앙첨단소재 2027.1, 해성 2027.5). 오버행 트리거를 (a)전환 개시 가능일과 (b)유통 가능 신주(3자배정분) 처분 공시로 분리 타이밍해야 함. 현 상태는 '실현'이 아니라 '적재(loaded)'.
- 초박 float 미시구조 발화 신호 강화: GMM은 역분할로 float 1.79M 축소 후 뉴스 없이 +117%(60배 거래)—펀더멘털이 아닌 시장구조 발화의 최청정 증거. 역분할→얇은 float는 preramp 게이트B의 강한 사전조건. 단 코스모로보틱스처럼 초저가 CB 전환신주가 곧바로 디스트리뷰션 연료가 되는 양면성 유의.
- 거짓양성 게이트로 감사리스크를 음(-)의 조정항에 편입해야 함: 알파AI·세니젠은 '사명변경+최대주주교체+핫테마 IR' 시그니처를 완비했으나 감사의견 거절/가공거래로 발화 없이 상폐 경로로 이탈. 시그니처 부착≠발화이므로 우도비 산정 시 감사의견·계속기업 불확실성을 게이트로 병기하지 않으면 셋업 신호가 거짓양성을 대량 생성.
- reAlpha 교훈: 역분할 후 '상장유지 성공'과 '작전 preramp'는 구별되며, 컴플라이언스 재획득 직후 희석성 공모는 이그니션이 아니라 러너웨이 연장(자금난) 신호. 초박 float에 대한 공모는 float을 넓혀 셋업 전제를 스스로 깨는 반증. 호재 아닌 희석을 촉매로 오인한 리테일 팝은 디스트리뷰션 창구로 기능 가능.
