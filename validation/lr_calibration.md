# 우도비(LR) 캘리브레이션 — 급상승 채널 시그니처 보유율

> 급상승(상한가) 리스트를 역스캔해 **우리 A~F 시그니처 보유율**을 측정하고, 대조군(안 터진 코스닥 소형주)과 비교해 **변별력(우도비 LR)**을 산출한다.
> ⚠️ 조작 단정 아님. SIGNATURE=구조 부합 관찰 후보 / LEGIT=실적·정상 M&A·규제뉴스 / UNCLEAR=코어 불부합 소프트플래그.

## ★ 첫 우도비 산출 (2026-08-06)

|  | 케이스(상한가 top10) | 대조군(비급등 소형주) |
|---|---|---|
| 표본 n | 10 | 16 |
| SIGNATURE | 2 | 0 |
| 엄격 시그니처율 | **20%** | **0.0%** |
| 소프트율(+UNCLEAR) | 50% | 6.2% |

### 결과
- **LR(엄격) ≈ 7.7×**, LR(소프트) ≈ 5.7× · Odds Ratio ≈ 9.7~10.3× (연속성 보정 적용)
- 해석: **A~F 시그니처를 가진 종목은 상한가(급등) 집단에 속할 승산이 약 6~10배 높다.**
- 핵심: 평범한 코스닥 소형주 16개 중 **SIGNATURE는 0개**(구조 자체가 일반 종목엔 거의 부재, 대조군율 ~0~6%). 반면 상한가 top10엔 20%가 보유 → 변별력이 실재.

### ⚠️ 이 숫자의 한계 (과대해석 금지)
1. **표본 극소**(케이스 10, 대조군 16) → 신뢰구간 매우 넓음. 단일일 스냅샷. 여러 날 반복 축적 필요.
2. **결과변수는 '급등'이지 '작전'이 아니다.** 이 LR은 "시그니처→급등" 승산이며, "시그니처→시세조종"이 아니다(급등≠조작). 조작 라벨과의 LR은 형사확정 앵커 대비 별도 측정.
3. **케이스=하루치 상한가 상위, 대조군=하루치 비급등**. 시총 대역만 대략 매칭(300억~5,000억), 업종 정밀매칭은 미적용.
4. 403 데이터 차단으로 일부 등락률 추정.
→ **잠정 신호**: 변별력이 있어 보이나(LR≈6~10×), 확정은 다회 반복·조작앵커 대비 측정 후.
