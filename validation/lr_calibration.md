# 우도비(LR) 캘리브레이션 — 급상승 채널 시그니처 보유율

> 급상승(상한가) 리스트를 역스캔해 **우리 A~F 시그니처 보유율(=시그니처 정밀도의 첫 실측)**을 시장·날짜별로 기록.
> LR ≈ P(시그니처|급등) / P(시그니처|비급등 대조군). 아래는 분자 쪽 base rate 축적. 대조군 시그니처율은 별도 측정 예정.
> ⚠️ 조작 단정 아님. SIGNATURE=구조 부합 관찰 후보 / LEGIT=실적·정상 M&A / UNCLEAR=코어 불부합·소프트플래그.
