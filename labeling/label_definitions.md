## v0.3 개정 로그 — 이원 라벨 체계 (O3 채택)

**결정**: 실사례 38건 유형 분석(`manipulation_typology.md`) 결과, 부당이득 최대 사건들(SG 7,305억·영풍제지 6,616억)이 전부 **T2(은밀매집형) = PCR-MS 게이트 A의 구조적 사각지대**임이 확인됨. 세 옵션 중:
- O1(코어 불변+층화): T2~T4를 전향적으로 검출 불가 → 발굴 목적에 미달.
- O2(게이트 A OR 완화): flow 지표를 라벨에 넣으면 BCI/APS 검증이 순환 오염 → **축 분리 위반으로 기각**.
- **O3(이원 라벨) 채택**: 두 독립 라벨을 fold 분리 운영.

**체계**:
1. **L1 = PCR-MS** (T1 소매홍보형·T5 착시군중형 대상) — 기존 코어 그대로. 게이트 A+B+D, 붕괴 층화.
2. **L2 = REG-ENF-C** (T2 은밀매집·T3 MM봇·T4 기관형 대상) — **형사 유죄 확정(A1)·plea(A2)만** 양성(기소 A3 이하는 pending 보류). 홍보축과 무관하므로 **BCI/APS 등 flow 시그널의 LR을 L2 대비 산출해도 순환 없음**(축 분리 유지). 검출편향(당국이 못 잡은 T2는 음성에 잔류)은 한계로 명시, C3 개념 역방향 적용.
3. **fold 규칙**: 시그널 LR은 유형-라벨 정합 fold에서만: P2(촉매 케이던스)→L1 fold, P1/P4(BCI/APS)→L2 fold 우선(+L1 보조). 유형별 기저율 분리, pooling 금지 유지.
4. **전향적 스크리닝**(모니터링 코호트 진입)은 라벨이 아님 — 게이트 A+B(진행형) OR 실시간 REG-ENF T1/T2(조회공시·투자경고) OR flow 프록시 극단. 스크리닝 점수는 **검증된 확률이 아니라 보정 전 유사도**로 표기(우도비 실측 전).

**한계(정직 공개)**: L2는 표본 소수(A1·A2 = 12건)·검출편향 잔존. L2 기반 LR은 "적발된 조작" 대비 변별력이며 전체 조작 대비가 아님. 이 결정은 잠정이며 전향적 검증에서 L2 fold 예측력이 무너지면 재검토.
**결정 주체**: 사용자 위임("라벨 방향 목적성에 맞게 자율 판단") 하에 자율 채택, 2026-07-02.

## ✅ 채택 정의: PCR-MS v0.1
**Promotion-Coupled Runup, Market-Adjusted, with Collapse-Stratification**
(시장조정 홍보급등 사건 + 붕괴 층화)

### 최상위 규칙 — 축 분리 (Construct Separation)
라벨은 **검증할 선행 시그널과 어떤 관찰축도 공유하지 않는다.**
- 라벨 구성 축: (a) 가격 결과사실(급등), (b) 공시 촉매, (c) 시장조정 붕괴(층화 전용).
- **검증 대상 시그널로만 남기는 축**: `sentiment`(관심 스파이크), `flow-actors`(매집·창구집중), `price-volume` 파생 모멘텀.
- 이유: 라벨과 시그널이 같은 축을 쓰면 자기상관으로 우도비(LR)가 자동 부풀려짐(순환). 시간창 분리만으로는 못 막음 → **축 분리**가 정답.

### 사건 축 확정 (알고리즘, 사후 지목 금지)
- **t_start**(급등 기점): 게이트 B의 변동성 정규화 급등 지표를 *처음* 상향 돌파한 날. t0 정보 미사용. 누출 회귀테스트(unit test)로 강제.
- **t0**(급등 종료점): 단일 지역최고가가 아니라 "변동성 정규화 급등 레짐이 꺼지는 시점". double-top·다봉은 하나의 사건으로 병합. `K∈{5,7,10}`·`Wd` 감도분석으로 label flip rate 보고, flip rate 높은 경계사건은 **gray zone**으로 격리(양성/대조군 어디에도 미포함).

### 코어 게이트 (A + B + D 모두 만족 → `label_positive=1`)

| 게이트 | 내용 | 핵심 조건 |
|---|---|---|
| **A. 홍보 결합** | 저품질 촉매 **단독** | `t_start~t0` 창 내 사전등록 폐쇄형 taxonomy의 내러티브형 촉매(사업목적 추가, MOU/LOI, 무·유상증자, CB/BW, 최대주주 변경, 테마 편입성 보도자료 등) **1건 이상**. sentiment 스파이크는 **제외**(as-of 동결 불가·생존편향·순환). 촉매가 매집 시그널과 강하게 공변하면 해당 촉매 제외(순환 재유입 봉쇄). |
| **B. 급등(시장조정)** | beta/섹터 조정 초과수익 | `t_start~t0` 누적 **초과수익**이 동일 자산군 횡단면 극단. 참조분포 = `t_start` 이전까지 rolling/expanding + **leave-one-out**(자기포함·t0시점 분포 금지). |
| **D. 펀더멘탈 무근거** | 블라인드 판정 | 급등 정당화할 검증가능 실적/현금흐름/완결 계약 부재. 판정자에게 t0 이후(붕괴·향후가격) **블라인드**, t0 이전 정보만 제공. **2인 독립 + Cohen's kappa** 보고, 경계·kappa 미달은 gray zone. crypto는 "검증가능한 온체인/프로토콜 이벤트 부재"로 재정의. |

### 게이트 C — 붕괴 (라벨 아님 · 층화 전용)
`t0` 이후 `Wd` 내 **시장조정 초과 되돌림**으로 측정. 양성을 하위분류:
- `collapsed`(붕괴 완결) / `uncollapsed`(성공한 펌프, 장기창까지 미붕괴) / `censored`(관찰 미완).
- **우도비는 `{collapsed ∪ uncollapsed}` 대 대조군**으로 계산 → '성공한 조작'이 음성으로 새는 종속변수 선택 편향 차단.

### 대조군 이원화
- **C1 (방법론 표준)**: 동일 시기·시총·섹터/체인의 무급등 매칭 종목 → 무조건부 기저율·무조건부 LR 분모.
- **C2 (hype-matched challenge set)**: 게이트 A+B는 만족하나 코어 양성 아닌 종목 → 표면신호만으로 변별 불가함을 보이는 LR 상한 진단. 충분한 사후 미붕괴 관찰기간 조건으로 진행중 조작 오염 차단.
- 어느 대조군이 어느 LR의 분모인지 `analysis/features.md`·`likelihood_table.md`에 명세.

### LR 측정 가능 시그널 스코프 제약
정직하게 LR 측정 가능한 시그널 = 주로 **t0 이전 `flow-actors`(창구/지갑 집중)** 계열.
`price-volume`/모멘텀/변동성 파생은 게이트 B와 공선 → 라벨에 쓴 축 기반 시그널은 그 fold의 LR 계산에서 **제외**.

### 임계값 (모두 범위 + 자산군별 개별 + 사전등록)
- **게이트 B 급등**: 시장조정 누적 초과수익 동일 자산군 rolling 횡단면 상위 95~99.5pct(권장 99). 보조: 급등폭/사전 실현변동성 ≥ 4~8σ(백분위와 병행, σ 단독 금지). 참고 절대치(자산군별): kr 20일 +60~150%(권장 +100%), crypto 14일 +150~400%, global 20일 +50~120%.
- **게이트 C 붕괴(층화)**: 시장조정 초과 되돌림 `(peak−저점)/(peak−t_start가) ≥ 0.5~0.7`(권장 0.6), `Wd`=10~40영업일(kr 20/crypto 14/global 30). `uncollapsed`: t0+장기창(예: t0+6개월 또는 2·Wd 이상)까지 미붕괴.
- **게이트 D**: 정성, 블라인드 2인+·kappa 보고, ±5일 내 감사된 실적서프라이즈·완결거래 있으면 배제.
- **t0/K**: `K∈{5,7,10}` 감도분석, flip rate 보고.
- **정규화**: rolling/expanding·leave-one-out, 상하위 1% winsorize, 저유동성 별도처리/제외.
- **유니버스 경계**: 거래소·시총 하한·스팩/관리종목/신규상장 배제·crypto 시총 상위 N — 모두 사전등록 + `label_version` 기록, 홀드아웃 밖 재튜닝 금지.

## ❌ 기각 (Rejected)

1. **CWMS 전체** — 3렌즈(편향/누출/순환) 만장일치 `fatal`. 구조적 3중 결함: (1) 4 pillar를 결과창에서 측정 → '조작 여부'가 아닌 '급등락 격렬함' 동어반복, (2) 라벨·검증시그널 동일축 → 시간창 분리로 순환 미차단, (3) **대조군에 t0 없어 CWMS 정의 불가 → 케이스-컨트롤 붕괴**. 단 개별 pillar는 `analysis/` 파생지표로 이관(폐기 아님).
2. **게이트 A에 sentiment 포함(PCRC 원안 요소)** — 순환(attention 시그널 검증 오염) + as-of 동결 불가(사후 삭제/정지) + 생존편향. 저품질 촉매(공시) 단독으로 축소, sentiment는 검증 시그널로만.
3. **붕괴를 라벨 필수게이트로 유지(PCRC 원안 요소)** — 종속변수 선택 편향 재발('성공한 펌프'가 대조군으로 오분류). outcome 층화축으로 강등.

## 🔄 개정 규칙 (Revisable)

v0.1은 **가설로서의 라벨**이다. 아래 시 반드시 개정하고 `label_version`을 올려 이 로그에 사유 기록:
1. t0/K/Wd 감도분석 flip rate 과다 또는 gray zone 비율 과도 → 사건 축 수정
2. 게이트 D kappa 임계 미달 → 정량 프록시 비중↑ 또는 재설계
3. 저품질 촉매 ↔ 매집 시그널 사전 상관 높음 → 해당 촉매 게이트 A에서 제외
4. 대조군 이원화 후 C2 LR이 1 근처 → 코어 게이트 재검토
5. 전향적(out-of-sample) 예측력 붕괴 → 라벨이 '실패한/약한 조작' 편향 가능성 재평가

**최종 판정은 과거 적합이 아니라 미래 예측(전향적 out-of-sample)으로 내린다.**

## v0.2 개정 로그 (3각도 탐색 완료 → 보조 재배치)

복구된 3각도를 각각 후보로 생성·적대검증했고 **모두 코어 라벨로 fatal**로 확정, 코어를 끌어내릴 근거 없음 → **코어 정의(PCR-MS) 불변**. 세 후보의 치명 결함은 동형(축 분리 위배 + '급등락 격렬함' 동어반복 + 검출/선택 편향)으로, 모두 PCR-MS가 이미 해결한 것을 되돌린다.

- **PVAR (price_quant)** — 코어 미승격. 3역할 재배치: (1) **C2 hype-matched 대조군 자동 생성기**(급등∧거래량이상=게이트A+B 만족·코어 양성 아닌 집합; 대조군은 축 공유가 목적이라 순환 소멸), (2) **1차 정량 스크리너**(게이트 A/D 심사 대상 선별, 인력 병목 완화), (3) 변동성 정규화 급등지표·up/down volume ratio·회전율 배수를 **게이트 B 계산규약 + `analysis/` 거래량 파생**으로 흡수(단 게이트 B 공선이라 해당 fold LR 제외).
- **REG-ENF (regulatory)** — 코어 기각, **kr 한정 보조축**으로만: (a) PCR-MS 양성과 concordance(외적 타당도), (b) 기저율 **하한 앵커** P_lower(참값은 이보다 큼 명시), (c) 전향적 모니터링 진입 트리거(T1 조회공시/T2 투자경고 실시간). ※ REG-ENF로 flow/모멘텀/price-volume LR 산출 **금지**(트리거가 동일 관찰축=순환). crypto 유의종목 기준 불투명 → 보류.
- **CANR-U (cross_asset)** — 독립 라벨 기각. 이중 정규화 표기(벤치마크 차감 + 실현변동성/MAD 무차원화)만 **게이트 B 정규화 규약**으로 흡수하되 "비교가능 표기일 뿐 pooling 근거 아님"을 못박음. 진짜 cross_asset 대응 = **게이트 A/D의 자산군별 어댑터 테이블**(A={kr 공시 taxonomy, crypto 온체인/토크노믹스, global 8-K/PR}; D crypto="검증가능 온체인/프로토콜 이벤트 부재").

**신설 규칙(v0.2)**:
- **t0 이원화** — REG-ENF 당국이벤트 published_at은 `detection_time`으로만 저장, 사건축 t0로 미사용(후행앵커라 선행윈도우 오염). t_start/t0는 PCR-MS 규칙기반 독립 재계산.
- **검출누락률(under-detection)** — challenge set에 **C3 = silent positives**(PCR-MS 양성인데 당국이벤트 없음) 추가, `|C3|/|양성|` 보고.
- **대조군 placebo-t0** — C1에 매칭 양성의 t0를 calendar-matched 이식(또는 자체 최대 z 결합일). 케이스-컨트롤 성립을 위한 공백 보완.

## 도출 과정 (Provenance)

- 방식: 오푸스 멀티에이전트 — (v0.1) 5각도 생성 → 3렌즈 적대검증 → 종합. (v0.2) 실패 3각도 복구 → 적대검증 → 시그널 발굴·순위 → 종합.
- v0.1 한계였던 **3각도 미탐색이 v0.2에서 해소**: price_quant(PVAR)·regulatory(REG-ENF)·cross_asset(CANR-U)로 각각 탐색, 모두 코어 fatal → 보조 재배치(위 로그).
- `label_version`: **v0.2** (코어 정의 불변, 결정 로그·사전등록 항목 추가)
