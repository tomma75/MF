# 마피아42 화면 구조 (학습 문서)

이 파일은 에이전트가 화면을 인식하며 스스로 갱신한다.
좌표는 세로 1080x2400 해상도 기준이며, 다른 해상도면 다시 학습해야 한다.

## 화면 판별법
| 화면 | 판별 단서 (OCR 텍스트) |
|------|------------------------|
| 로비 | (미학습) |
| 대기방 | (미학습) |
| 게임 중 - 낮 토론 | (미학습) |
| 게임 중 - 투표 | (미학습) |
| 게임 중 - 밤 | (미학습) |
| 게임 종료/결과 | (미학습) |

## 주요 버튼 좌표
| 요소 | 좌표 (x, y) | 비고 |
|------|-------------|------|
| 채팅 입력창 | (미학습) | config.json의 chat_input과 맞출 것 |
| 채팅 전송 버튼 | (미학습) | config.json의 send_button과 맞출 것 |
| 투표 확정 버튼 | (미학습) | |
| 준비/다시하기 버튼 | (미학습) | |

## 플레이어 슬롯 좌표 (12인 기준)
(미학습 — 투표 화면에서 각 플레이어 이름 OCR 좌표를 근거로 기록할 것)

## 갱신 규칙
- 새 화면 종류를 판별할 단서를 찾으면 위 표에 추가한다.
- 버튼을 눌러서 의도대로 동작했음을 확인한 좌표만 기록한다.
- 좌표가 틀렸던 기록은 지우거나 정정한다.
