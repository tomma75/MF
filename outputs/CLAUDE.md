# outputs/ — 교육 산출물 (Educational Deliverables)

> 목적: 검증 통과한 결과를 **지인 교육용**으로 가공한다.
> 모든 산출물에 **면책(교육·연구용, 투자자문 아님)** 을 명시한다(루트 윤리 상속).

## 산출물 4종 (사용자 선택)
- `case-studies/` — **사례연구 리포트(md)**: 개별 종목/사건을 타임라인 + 심리 관점으로 서술. 실명 단정 금지·익명화.
- `patterns-checklists/` — **패턴·체크리스트**: 검증된 시그널을 일반인이 쓸 수 있는 경고 체크리스트로 요약.
- `decks/` — **강의·발표 자료**: 슬라이드 구조/스크립트. 군중심리 사례 중심.
- `datasets-stats/` — **데이터셋·통계·시각화**: 정제 데이터 + 우도비/리드타임 차트.

## 품질 규칙
- 모든 주장에 **근거(analysis/validation 링크)**. 검증 안 된 시그널은 "가설"로 표기.
- 대조군 비교 결과를 반드시 함께 제시(거짓양성 솔직 공개).
- 교육 메시지: "이 패턴이 보이면 **조심하라**"(방어), 절대 "**따라 사라**"(추종) 아님.

## 사례연구 템플릿(권장)
```
# [익명코드] 사례
- 자산군 / 시기 / 정의버전(label_version)
- 타임라인: t-N … t0(터짐) … 이후
- 관찰된 시그널(데이터 종류별) + 우도비
- 대조군 대비
- 군중심리 해설(공포·탐욕·FOMO·확증편향)
- 교훈 / 경고 신호 체크
- ⚠️ 면책
```
