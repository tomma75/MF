# MF — 작전주 시그널 분석 & 군중심리 교육 워크스페이스

작전주(market-manipulation stock)가 "터지기" 전에 남기는 데이터적 흔적을 수집·분석하고,
이를 실사례에 접목해 **지인 교육용 자료**로 만들며, 그 과정의 **군중심리**를 데이터로 설명하는 연구 워크스페이스.

> **방어적·교육적 목적.** 조작을 *식별·회피*하기 위한 것이며, *수행*을 위한 것이 아니다.
> 모든 산출물은 교육·연구용이며 투자 자문이 아니다.

## 구조 (트리 루트 = 데이터 종류별)

```
CLAUDE.md                  # 프로젝트 헌법 + 라우팅 맵 (먼저 읽기)
data/                      # 원천 데이터 (데이터 종류별 분기)
  price-volume/            #   가격·거래량
  disclosure-news/         #   공시·뉴스 (근거자료 아카이브)
  sentiment/               #   커뮤니티·여론 심리
  flow-actors/             #   수급 주체·세력
labeling/                  # [횡단] 양성 라벨 정의(미확정) + 대조군 매칭
analysis/                  # [횡단] 시그널 추출·우도비·event study
validation/                # [횡단] 전향적 검증(1개월 모니터링)·홀드아웃
outputs/                   # [횡단] 교육 산출물(사례·체크리스트·발표·데이터셋)
```

각 디렉토리에는 그 디렉토리에서만 필요한 규칙을 담은 `CLAUDE.md`가 있다.
작업 시 **루트 CLAUDE.md + 해당 디렉토리 CLAUDE.md만** 읽어 토큰을 아낀다.

## 설계 원칙 (요약)
- 케이스-컨트롤 + 사건연구로 **종속변수 선택 편향** 차단
- "공통점 나열" 대신 **우도비(LR)/lift**로 변별력 측정
- **as-of 동결**로 미래정보 누출 방지
- **전향적 검증**이 시그널 최종 판정 (검증 후 자동화)
- **작전주 정의는 미확정** — 임의 특정 금지, 가설로만 보관

자세한 내용은 `CLAUDE.md` 참조.
